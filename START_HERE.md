# Nata – Start

## Wichtig
Diese Website ist ein **Vite-Projekt**. Die `index.html` ist der Einstiegspunkt, aber
die JavaScript- und CSS-Dateien werden über Vite aus `src/` geladen.

### Start
```bash
npm install
npm run dev
```

Danach die von Vite angezeigte lokale Adresse öffnen.

### Build
```bash
npm run build
npm run preview
```

## Struktur
- `index.html` – HTML-Einstiegspunkt
- `src/main.js` – App-Bootstrap
- `src/components/` – wiederverwendbare UI
- `src/sections/` – komplette Nata-Seitenbereiche
- `src/styles/` – CSS/Tokens/Animationen/Responsive
- `src/lib/` – JavaScript-Interaktionen
- `public/assets/` – Nata-Visuals
